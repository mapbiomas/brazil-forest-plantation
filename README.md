## About

This repository contains scripts used for the forest plantation theme included in MapBiomas Brazil' Land Use Land Cover maps. We recommend that you read the  [Agriculture Appendix of the Algorithm Theoretical Basis Document (ATBD)](https://mapbiomas.org/download-dos-atbds), since important informations about the classification methodology can be found there.
